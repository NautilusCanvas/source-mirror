asks for it, exactly as built. Generated by tools/make-source-mirror.sh
from the repository at 2a2ae411.

## LibRaw 0.22.2

- Licence: CDDL-1.0, elected (LibRaw is offered under LGPL-2.1-only or
  CDDL-1.0). Copyright (C) 2008-2025 LibRaw LLC.
- `libraw/LibRaw-0.22.2.tar.gz`: LibRaw's release, tag
  0.22.2, from https://github.com/LibRaw/LibRaw.
- `libraw/LibRaw-cmake-eb98e43.tar.gz`: the build files, from
  https://github.com/LibRaw/LibRaw-cmake at eb98e4325aef2ce85d2eb031c2ff18640ca616d3.
- `libraw/patches/`: applied in this order by vcpkg's overlay port.
  To LibRaw: wavelet-denoise-size.patch, then fujifilm-x-e5-matrix.patch,
  Nautilus Canvas's modifications, each explained in its header. To
  LibRaw-cmake: dependencies.patch, then fix-install.patch, vcpkg's.
- Built as libraw_r, the thread-safe library, with OpenMP, by vcpkg; the
  port and its triplet are in the Nautilus Canvas repository under
  third_party/vcpkg.
